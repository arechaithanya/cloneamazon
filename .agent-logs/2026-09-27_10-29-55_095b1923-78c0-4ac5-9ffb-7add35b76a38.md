## ⚠️ One issue to expect

SQLite (`dev.db`) is a local file — Vercel's filesystem is **ephemeral**, meaning the database resets on every deployment. This means:

- Static pages (home, products, category pages) → ✅ work perfectly
- Cart/checkout/orders (need the DB) → ❌ may error on Vercel

**Quick fix options:**
1. **Turso** (SQLite hosted in the cloud, free) — swap `DATABASE_URL` to a Turso URL, works with Prisma
2. **Neon** (Postgres, free) — change `schema.prisma` provider to `postgresql`
